# 7. ARCHIVE, RESTORE, AND DELETE

ARCHIVE

Archiving should:

- Set archived_at
- Set status to Archived
- Keep the record and related notes
- Remove the client from the default active list
- Log the activity

RESTORE

Restoring should:

- Clear archived_at
- Require the Administrator to select a valid restored status
- Log the activity

PERMANENT DELETE

Permanent deletion should:

- Be available only for archived clients
- Use a strong confirmation dialog
- Require confirmation using the company name or the word DELETE
- Explain that client notes will also be removed
- Use a database transaction
- Log the deletion before removing the record when technically possible

Do not accidentally expose permanent deletion as the primary action.
