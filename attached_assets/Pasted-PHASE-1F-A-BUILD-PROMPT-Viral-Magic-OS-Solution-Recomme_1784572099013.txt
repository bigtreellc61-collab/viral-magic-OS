3. RECOMMENDATION PLAN
==================================================

A Solution Recommendation Plan must be generated from a Growth Assessment.

Default rule:

- Plan should be generated from an approved Growth Assessment.
- If the assessment is not approved, reject generation with a clear message.
- Only one active plan may exist for the same Growth Assessment.
- Older approved plans must never be overwritten.
- Regeneration is allowed only while the plan is Draft or Reopened.

Required plan statuses:

- draft
- awaiting_review
- approved
- reopened
- superseded
- archived

Status transitions:

draft
→ awaiting_review
→ approved

approved
→ reopened
→ draft

approved
→ superseded

draft / approved / superseded
→ archived

7. PRIORITY SCORING
==================================================

Create named constants at the top of the recommendation engine.

Priority score components:

- Severity
- Business impact
- Urgency
- Performance gap
- Quick-win bonus
- Dependency importance
- Effort penalty

Normalize the score to 0–100.

Suggested classification:

- 90–100 — Critical Priority
- 80–89 — High Priority
- 65–79 — Important
- 50–64 — Planned Improvement
- 0–49 — Monitor

Store a scoring explanation for every recommendation.

Example scoring explanation:

{
  "severity": 20,
  "businessImpact": 20,
  "urgency": 15,
  "performanceGap": 18,
  "quickWinBonus": 8,
  "dependencyBonus": 5,
  "effortPenalty": -6,
  "finalScore": 80
}

Do not rely only on the existing Phase 1E priority score.

Quick-win rule:

- Impact is high

11. STATUS RULES
==================================================

Draft:

- Editable
- Can regenerate
- Can submit for review

Awaiting Review:

- Cannot regenerate
- Can approve
- Can reopen

Approved:

- Read-only
- Can reopen
- Can archive
- Can be superseded by a newer approved plan

Reopened:

- Editable
- Can regenerate
- Returns to Draft when saved

Archived:

- Read-only

Approval requirements:

- At least one recommendation
- Executive Recommendation exists
- Every top recommendation has a success metric
- No circular dependencies
- No invalid recommendation rank
- No score outside 0–100
