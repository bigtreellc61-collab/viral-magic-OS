# PHASE 1C OBJECTIVE

Build a complete internal Project Management and Task Management module.

The Administrator must be able to:

1. View all projects
2. Search, filter, and sort projects
3. Create a project
4. Attach a project to an existing client
5. View a project record
6. Edit a project
7. Change project status
8. Archive and restore a project
9. Permanently delete only an archived project after strong confirmation
10. Create, edit, complete, archive, restore, and delete project tasks
11. View project activity history
12. View project progress
13. See real project and task metrics on the Dashboard

All project and task data must persist in PostgreSQL.

# 6. PROJECT PROGRESS

Calculate project progress from tasks.

Default formula:

Completed non-cancelled tasks divided by total non-cancelled tasks × 100.

Rules:

- If no tasks exist, show 0% and “No tasks created”
- Cancelled and archived tasks do not count
- Completed tasks count as complete
- Project completion does not automatically occur unless the Administrator confirms it
- If project status is Completed, show 100% only when all active tasks are completed or display a warning

Display:

- Progress bar
- Completed task count
- Open task count
- Blocked task count
- Overdue task count

# 10. ARCHIVE, RESTORE, AND DELETE

PROJECT ARCHIVE

- Set archived_at
- Set status to Archived
- Preserve tasks
- Hide from default list
- Log activity

PROJECT RESTORE

- Clear archived_at
- Require selection of a valid restored status
- Restore tasks only if explicitly selected
- Log activity

PROJECT PERMANENT DELETE

- Only archived projects may be deleted
- Require company or project name confirmation
- Explain that linked tasks will be deleted
- Use a transaction
- Log before deletion when technically possible

TASK ARCHIVE

- Set archived_at
- Set status to Archived
- Hide from default task views
- Log activity

TASK RESTORE

- Clear archived_at
- Require valid restored status
- Log activity

TASK DELETE

- Only archived tasks
- Strong confirmation required
